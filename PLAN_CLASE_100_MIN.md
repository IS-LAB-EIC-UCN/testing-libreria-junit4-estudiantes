# Plan de clase (100 minutos) — alternancia diapositivas/código

| Tiempo | Diapositivas | Demostración / actividad | Participación |
|---:|---|---|---|
| 0–5 | 2–4, 6–10 | ¿Cuál test falta para factorial? Explicar Arrange–Act–Assert. | Proponer `factorial(0)`, `factorial(3)` y un límite |
| 5–25 | 15–24 | Ejecutar `SimpleStackTest`; completar caso LIFO; reparar `pop`. | Parejas, test rojo/verde |
| 25–35 | 26–35 | Repasar FIRST, excepción, independencia y cobertura JaCoCo. | Explicar por qué cobertura no garantiza corrección |
| 35–60 | 40–49 | Crear fake manual y, luego, Mockito (`when`/`verify`). | Pruebas con ISBN válido e inválido |
| 60–85 | 51–61 | TDD para `ShoppingCart`: un requisito a la vez. | Rojo → verde → refactor |
| 85–95 | 62–67 | Probar `OrderService` con repositorio en memoria. | Distinguir unidad de integración |
| 95–100 | — | Ticket de salida. | Respuestas individuales |

Si el curso se atrasa, dejar la actividad 5 como extensión y mantener obligatoriamente las actividades 1, 3 y 4.
